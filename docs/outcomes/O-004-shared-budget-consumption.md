# O-004 — Shared budget consumption

**Outcome** — Enable craftlions admins and client portal users to rely on the same current-year budget consumption wherever it appears so that next-year budgets and project selection start from shared actual spend.

**Success**

- I compare the same organization’s budget use between admin and client views: different today → identical.
- I open another view to verify budget use before trusting it: required today → unnecessary.
- We plan a client’s next budget or project mix from conflicting usage figures: possible today → never.
