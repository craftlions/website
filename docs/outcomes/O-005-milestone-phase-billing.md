# O-005 — Milestone phase billing

**Outcome** — Enable craftlions to price a phase in up to three cost components — upfront at approval, on delivery, on acceptance — each due when its milestone completes, so that revenue stops floating through the whole build and the client's acceptance pace.

**Success**

- A phase's entire cost hangs on final acceptance: every phase today → only phases priced that way.
- A slow acceptance holds the whole phase cost hostage: full exposure today → just the acceptance share.
- A client asks when they'll owe what: I explain by mail today → the portal shows the split and each component's status.
