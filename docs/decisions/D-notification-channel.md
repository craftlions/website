# Email as the only notification channel

Customer notifications — O-001's approval and overdue mails and every future feature that reaches customers outside the portal — use verified email as the sole outbound channel. Every customer already has a verified address, the mail infrastructure exists, and a one-person operation cannot run more channels well; Slack, SMS, webhooks, and browser push were deferred, not rejected on merit.

## Revisit when

A new channel is explored or customer feedback asks for one. This decision binds features beyond O-001, so adding any channel reopens it product-wide, not per feature.
