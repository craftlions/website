# Spend view placement

The year-over-year spend picture ([[O-002]]) lives as a section on the existing org dashboard, computed at request time from the invoices table — no new route, table, or precomputation. Clients already read and retell from the dashboard; adding navigation or infrastructure buys nothing the brief demands.

## Alternatives considered

A dedicated spend page (adds nav surface, splits spend across two places) and year-grouping the invoice list (per-project split fits poorly, weak at-a-glance comparison).

## Revisit when

The dashboard can no longer hold the full year history legibly.
